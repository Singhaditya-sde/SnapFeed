# 📸 SnapFeed

A simple Instagram-style photo sharing app built with **FastAPI + React**.

## 🚀 Features

- 📤 Upload images with captions
- 📰 View posts in a feed
- 🗄️ PostgreSQL database
- ⚡ FastAPI REST API
- ⚛️ React frontend

## 🛠️ Tech Stack

- FastAPI
- Python
- SQLAlchemy
- PostgreSQL
- React
- uv
